Stitch.js test suites

The automated gate is npm test: it runs every page below against stitch.js and stitch.min.js in headless Chromium and fails on any failed, skipped or unreported test. This page lists the same suites (read from tests/suites.js, the one suite list) so each can be opened by hand; every page shows a [harness] summary line at the top.

Some tests are expected to fail until their fix lands; they are listed in tests/known-failing.json and described in KNOWN-ISSUES.md.
