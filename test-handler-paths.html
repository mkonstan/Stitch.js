Handler paths

data-click and the handler names in a data-event map name a handler by a bare name (the current row; the model outside a list), $parent.name (one level up) or $root.name (the root model), and nothing else (D12). The handler is called with this = the object it is on and (rowItem, event). A name that is not found throws from bind(), saying where it was looked up and where it does exist.
