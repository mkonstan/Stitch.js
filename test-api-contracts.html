API contracts

Every subscription can be undone with what it returned ($watch, $onChange); isReactive answers true or false; a computed receives the object that holds it as its first argument (so an arrow function works through the argument); frozen or sealed data is refused with a Stitch message; every attribute a Stitch binding reads is reported as bound; a custom binding whose value is not a path says how to declare a literal binding; every Stitch error starts with a stable code, [Stitch E###].
