foreach: the key rule and the one-root rule

Every list row has a unique key: an object row's id, or the field named by data-key; a plain value is its own key. No fallback to the row index or to row.key. A missing or duplicate key throws. A row template has exactly one root element. The same rules hold on every list path: inline template, data-template, <select> options, table bodies, and lists that are re-rendered or set to null.
