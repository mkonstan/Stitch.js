Attribute safety

Values reach attributes through data-attr. Every value that could run script is refused with its code and writes nothing: event-handler names, srcdoc, javascript: and vbscript: URLs in any of their evasion forms, data: URLs (except data:image/ in an img src) and style strings. Legitimate values keep working; style objects are written through the CSSOM; script, style, base and meta elements cannot be bound.
